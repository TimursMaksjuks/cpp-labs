\# Lab 5 - Reversing a Singly Linked List



\## Description



This laboratory work contains implementation of a singly linked list reversal algorithm in C++.



The main task is to reverse a linked list without creating additional structures that duplicate the list data.

The reversal is performed only by reconnecting pointers between nodes.



\## Project Structure



\### Manual\_List\_Version

Interactive console application that allows the user to:

\- enter list elements,

\- display the original list,

\- reverse the list,

\- display the reversed list.



\### Manual\_List\_Test\_Version

Automated test version used to verify the correctness of the linked list reversal algorithm.



The tests include:

\- normal list reversal,

\- reversing a single-element list,

\- reversing an empty list,

\- reversing lists containing negative values.



\## Technologies Used



\- C++

\- Dynamic memory allocation

\- Singly linked lists

\- Pointer manipulation

\- Exception handling
