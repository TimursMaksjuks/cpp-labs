# Manual List Test Version

## Description

This project contains automated tests for verifying the correctness of a singly linked list reversal algorithm.

The implementation uses dynamic memory allocation and pointer manipulation.

## Files

- `test_main.cpp` — automated test cases
- `reverse_list.cpp` — linked list implementation
- `reverse_list.h` — structure and function declarations

## Implemented Tests

### Test 1
Checks correct reversal of a standard list.

### Test 2
Checks behavior when reversing a single-element list.

### Test 3
Checks behavior when reversing an empty list.

### Test 4
Checks reversal of a list containing negative values.

```text
Test 1: OK
Test 2: OK

Test 4: OK
```

## Features

- Automated validation
- Exception handling tests
- Linked list integrity verification
- Edge case testing
