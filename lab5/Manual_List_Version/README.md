# Manual List Version



## Description



This project implements a singly linked list using dynamic memory allocation in C++.



The program allows the user to:

- input list elements manually,

- display the original list,

- reverse the linked list,

- display the reversed list.



The list reversal is performed by reconnecting node pointers instead of copying element values.



## Files



- `main.cpp` — user interaction and program execution

- `reverse\_list.cpp` — linked list function implementations

- `reverse\_list.h` — structure and function declarations



## Features



- Dynamic memory management

- Pointer-based linked list implementation

- In-place list reversal

- Exception handling for invalid operations



## Example



Input:

```text

1 2 3 4 5

```



Output:

```text

Original list: 1 2 3 4 5

Reversed list: 5 4 3 2 1

```
