# Lab 2 – File Processing in C++

This program processes a text file in sequential mode.

The program reads a text file line by line and finds all words that contain a specified substring.

The found words are written to another file.

A word is defined as a sequence of characters separated by spaces or punctuation marks.

Files used in the program:

file_reading.txt – input text file  
file_writing.txt – output file with results

An example substring "pro" was used to test the program.  
The result of the program can be found in the file `file_writing.txt`.
